# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not publish vulnerabilities, credentials, private network details, or exploit code in a public issue. Use GitHub's private vulnerability-reporting flow when it is available for this repository; otherwise contact the maintainer through the repository owner's GitHub profile with a concise description, affected version, reproduction steps, and suggested mitigation.

The maintainer will acknowledge the report, investigate it, and coordinate disclosure before publishing a fix.
